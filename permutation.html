Permutation Testing: Differences Between Two Groups

Enter a group label and a numeric data value on each row. "Group" must include exactly two distinct labels (the first listed label is referred to as "Group 1" in the Hypothesis test selection). The test randomly reassigns the group labels while keeping the values fixed. It compares proportions when all Data values are 0 or 1; otherwise, it compares means.

  1. Paste two columns from a spreadsheet, or enter data directly in the table.
  2. Click “Run permutation test” to generate 10,000 permutations.
  3. The histogram shows the permuted differences; the vertical line marks the observed difference.
